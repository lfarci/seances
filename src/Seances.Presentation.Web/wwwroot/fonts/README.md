# Local fonts

Source Sans 3 is used for calendar titles, times, controls, and supporting text.
Source Serif 4 is reserved for page, cinema, and screening-detail headings.

The Latin variable WOFF2 files are from Fontsource packages version 5.2.8:

- https://www.npmjs.com/package/@fontsource-variable/source-sans-3/v/5.2.8
- https://www.npmjs.com/package/@fontsource-variable/source-serif-4/v/5.2.8

Both Adobe typefaces are distributed under the SIL Open Font License 1.1.
Their license texts are included alongside the fonts. Files are served locally;
no external font service is used by the app.
